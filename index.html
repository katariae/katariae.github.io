    how this is made

    One hand-written HTML file: no frameworks and no build step. Every animation is plain canvas drawing.

    The hero is a small particle simulation: your cursor acts like a mass, and clicking sends out an impulse. The orbits use Kepler's third law, and each observation card draws a fake detector event from a seeded random number generator.

    Designed and built together with Claude, hosted for free on GitHub Pages.
