# katariae.github.io

Personal site of Ekaksh (EK) Kataria.

- `data.js`: all site content (projects, roles, hikes, contact). Edit this file.
- `photos/`: hiking photos (JPG, about 1600px wide, under 500 KB).
- `index.html`: layout, styles and interactions.

To show a repo in the live "on the bench" section, add the topic `portfolio` to it on GitHub.
